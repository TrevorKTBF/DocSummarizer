Goal: Add a client-side “soft gate” overlay that appears on every visit until dismissed with a valid passcode. This is NOT real security—just a lightweight gate for vibe and onboarding.

Requirements:
- Overlay: Full-screen dimmed backdrop that disables interaction with the page until passed. Use rgba(0,0,0,0.6), pointer-events blocking, and prevent body scroll while active.
- Card: Small white box centered (max-width ~320px), rounded corners, subtle shadow, site fonts.
- Fields:
  - Single input for passcode (type="password"). Placeholder: “Enter passcode”.
  - Validation rule: passcode length must be >= 6 characters (i.e., more than five).
  - A checkbox labeled “Remember me” (checked by default).
  - A primary button labeled “Enter”.
- Behavior:
  - On first load, show the overlay. Focus the input automatically. Trap focus within the modal until valid.
  - On submit: if length >= 6, hide the overlay.
    - If “Remember me” is checked, set localStorage key "sf_gate_ok" = "1" so subsequent visits skip the gate.
    - If not checked, set sessionStorage key "sf_gate_ok" = "1" so it only skips for this tab/session.
  - On subsequent loads, if either key exists, do not render the overlay.
  - Show a small inline error message under the input if the passcode is too short.
- Accessibility:
  - role="dialog", aria-modal="true", aria-labelledby for the title, and associated label for the checkbox.
  - Ensure ESC does not close the gate (must meet validation).
- Tech constraints:
  - Implement in vanilla HTML/CSS/JS (no frameworks). It should work regardless of the existing stack.
  - Add a single gate script (e.g., /public/gate.js or /static/gate.js) and a style (or inject styles via JS).
  - Include the script near the end of <body> so it runs after DOM is ready.
  - Do not change routing or server config.

Files/changes to make:
1) Add this snippet just before </body> in index.html (or the main HTML template):
   <script src="/gate.js" defer></script>

2) Create gate.js with:
   - A self-invoking function that:
     - Checks localStorage/sessionStorage for "sf_gate_ok".
     - If not present, injects:
       - A <style> block with overlay/card styles.
       - The overlay HTML:
         <div id="sf-gate-overlay" ...>
           <div class="sf-card" role="dialog" aria-modal="true" aria-labelledby="sf-gate-title">
             <h2 id="sf-gate-title">Welcome</h2>
             <p class="sf-sub">Enter passcode to continue.</p>
             <form id="sf-gate-form" novalidate>
               <input id="sf-pass" type="password" inputmode="text" autocomplete="off" minlength="6" placeholder="Enter passcode" required />
               <label class="sf-remember">
                 <input id="sf-remember" type="checkbox" checked />
                 <span>Remember me</span>
               </label>
               <button id="sf-submit" type="submit">Enter</button>
               <div id="sf-error" aria-live="polite"></div>
             </form>
           </div>
         </div>
     - Applies body style overflow: hidden while overlay is visible.
     - Focuses #sf-pass on mount and traps focus within .sf-card.
     - On submit, validates length >= 6:
       * If invalid, prevent submission and show “Passcode must be at least 6 characters.”
       * If valid:
         - If #sf-remember checked: localStorage.setItem("sf_gate_ok","1")
         - Else: sessionStorage.setItem("sf_gate_ok","1")
         - Remove overlay, restore body scrolling, and release focus trap.

4) Make sure this gate loads on every page view by ensuring index.html (or the layout template) includes the script. Do not gate assets or break SSR.

5) Add a tiny utility function to allow manual reset (for testing):
   window.__sfResetGate = () => { localStorage.removeItem("sf_gate_ok"); sessionStorage.removeItem("sf_gate_ok"); location.reload(); }

Acceptance criteria:
- Fresh visit shows dimmed overlay with centered white box, input, “Remember me” checkbox, and “Enter” button.
- Entering fewer than 6 characters shows an inline error and does not dismiss the overlay.
- Entering 6+ characters with “Remember me” checked dismisses the overlay and future visits skip the gate.
- Entering 6+ characters with “Remember me” unchecked dismisses the overlay, but a hard refresh brings it back.
- While the overlay is visible, you cannot scroll or interact with the page behind it, and keyboard focus is trapped inside the modal.
- No network calls or backend changes are introduced.
